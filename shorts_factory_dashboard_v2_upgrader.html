อัปเดต Shorts Factory: รายการงาน ชื่อคลิป และดูวิดีโอ

เครื่องมือฟรีสำหรับสร้าง index.html เวอร์ชันใหม่จาก Dashboard เดิมของคุณ ไม่ต้องใช้ Claude Code, AI Token หรือ GitHub Token

เพิ่ม 3 ระบบใหม่

① ปุ่ม 🗑 ลบรายการ ในหน้า “สถานะงาน” และ “คลิป” (ซ่อนในอุปกรณ์นั้น ไม่ลบไฟล์จริง)
② บันทึกชื่อคลิปเมื่อกดสร้างงาน และผูกกับ GitHub Run ID เพื่อดูว่างานใดกำลังทำหรือผิดพลาด
③ ตัวเล่น MP4 ในเว็บ รองรับมือถือและ PC พร้อมวิธีเปิดไฟล์ต้นฉบับเมื่อที่เก็บไฟล์ไม่อนุญาตให้เล่นในหน้าเว็บ

มีปุ่ม ↶ คืนรายการที่ซ่อน และยังเก็บปุ่ม ยกเลิกงาน เดิมไว้

ขั้นที่ 1 — สร้าง Dashboard v2

ถ้าเว็บ GitHub โหลดไม่ได้ ให้เลือกไฟล์ index.html เดิมจากคอมพิวเตอร์:

พร้อมใช้งาน — เครื่องมือนี้สร้างไฟล์ให้ดาวน์โหลด ยังไม่ได้แก้ไขไฟล์บน GitHub ของคุณ

ขั้นที่ 2 — อัปโหลดไฟล์ใหม่ขึ้น GitHub

เปิด Repository Dashboard ของคุณ → Add file → Upload files → เลือกไฟล์ index.html ที่เพิ่งดาวน์โหลด → ยืนยัน Commit เพื่อแทนไฟล์เดิม

ถ้ามีหน้าต่างถามให้เขียนทับไฟล์ ให้เลือกแทนที่ไฟล์เก่า ตรวจว่า Repository และ branch เป็น main ก่อน Commit

หมายเหตุสำคัญ

• ปุ่มลบเป็นการซ่อนรายการในเบราว์เซอร์ปัจจุบัน จึงไม่ซิงก์ข้ามมือถือและ PC และไม่ลบข้อมูลจริงใน GitHub
• ชื่อคลิปที่สั่งใหม่จะผูกกับ Run ID บนอุปกรณ์ที่สั่ง ส่วนงานเก่าที่ GitHub ไม่เก็บชื่อไว้จะยังไม่ทราบชื่อเรื่องแน่นอน
• GitHub Release ของ Repository แบบ private อาจไม่สามารถเล่น MP4 โดยตรงในบางเบราว์เซอร์ได้ จึงมีลิงก์เปิดต้นฉบับสำรอง การเล่นได้ทุกเครื่องอาจต้องเผยแพร่ไฟล์ในแหล่งที่รองรับวิดีโอบนเว็บ
• ปุ่มยกเลิกต้องใช้ GitHub Token ที่มีสิทธิ์ Actions: Read and Write
